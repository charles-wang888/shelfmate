# Employee Discount Guidelines

## Benefit
Active employees receive **20% off** regular-priced merchandise and **10% off** already-discounted items.

## Limits
- Not valid on gift cards, services, licenses, or partner concessions.
- Friends-and-family events are announced separately and override these rates.
- Abuse (reselling discounted goods) is a termination offense.

## Ringing the discount
Use employee ID at POS. Managers must approve discounts above $200 in a single transaction.
